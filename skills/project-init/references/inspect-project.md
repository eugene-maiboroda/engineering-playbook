# Перевірка наявного проєкту

## Перевір наданий проєкт

Використай фактичний projectDirectory, переданий користувачем або запуском.
Прочитай наявні AGENTS.md і progress. Не створюй skeleton і не замінюй
наявний проєкт шаблоном. Перевір лише дозволені матеріали.

## Inspect Created Project

Досліди фактичний стан підключеного проєкту.

Перевір:

- `pom.xml` / build configuration;
- фактичну Java version;
- Spring Boot version;
- dependencies;
- package structure;
- existing configuration;
- Git structure;
- вже створені файли та компоненти.

Попередні рекомендації після цього не є source of truth — source of truth є фактичний стан створеного проєкту.

Якщо між рекомендаціями/стандартами й створеним проєктом є важливі
розбіжності — поясни їх та запропонуй варіанти. Збережи унікальні компоненти
користувача. Не повертай версії чи конфігурацію до defaults автоматично;
зміни виконуй лише після відповідного доручення.

## Заверши перевірку

Запиши в спільний progress фактичний стан skeleton, перевірені файли,
важливі розбіжності й те, що залишилося неперевіреним. Поверни ці
результати до поточного кроку Skill, який направив тебе на перевірку.
Якщо важлива розбіжність потребує рішення користувача, явно познач її.
Не запускай Planning або реалізацію в межах цієї перевірки.
