# Engineering Playbook

Моя особиста інженерна база знань і правил для роботи з AI-агентами.

## Розділи

- `ai-rules/` — конкретні інструкції для AI-агентів.
- `research/` — дослідження інженерних тем.
- `principles/` — короткі інженерні принципи та висновки.
- `checklists/` — робочі чеклісти.
- `decisions/` — архітектурні рішення та ADR.

## Статус

Система розвивається поступово на основі реальних проєктів і задач.

## Підключення локальної бази

Engineering Playbook використовується як локальна база документів, без
plugin і marketplace. Передай агенту абсолютний корінь цільового проєкту,
абсолютний корінь Playbook і шлях початкового Skill. Правила пошуку —
[підключення через AGENTS.md](ai-rules/references/project-agent-instructions.md#розташування-playbook-і-пошук-документів).

Між Skills зберігаємо назву `engineering-playbook:назва` та обов’язкове
файлове посилання на SKILL.md. Префікс — умовна назва в документах, а не
зареєстрована команда plugin. References, prompts і AI rules мають прямі
файлові посилання. Читання потрібного Skill не надає дозволу на його
виконання або запуск додаткових агентів.
